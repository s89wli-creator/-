# 04 — خريطة الشاشات (Screen Map)

> Arabic-first، RTL، Desktop-first للإدارة، Mobile-first للمندوب.
> كل شاشة مرتبطة بالأدوار التي تراها ومتطلبات PRD.

---

## 1. البنية العامة للتنقل

```
/login, /forgot-password, /invite/:token, /mfa
/onboarding                 (معالج إعداد الشركة — Owner)

/(manager)  ── شريط جانبي (يمين في RTL)
  ├─ /dashboard
  ├─ /ask                    (اسأل راكان — Orchestrator chat)
  ├─ /leads                  (العملاء المحتملون)
  │    ├─ /leads/:id         (ملف العميل)
  │    ├─ /leads/import      (استيراد)
  │    └─ /leads/discover    (البحث عن الشركات — Prospecting)
  ├─ /analysis               (تحليل العملاء / الأولويات)
  ├─ /pipeline               (خط المبيعات — Kanban + قائمة)
  │    └─ /pipeline/:oppId
  ├─ /visits                 (التقويم + الخريطة + القائمة)
  │    └─ /visits/:id        (تفاصيل الزيارة + التحليل)
  ├─ /tasks                  (المهام والمتابعات)
  ├─ /approvals              (طابور الموافقات)
  ├─ /reports                (التقارير + KPIs)
  ├─ /brain                  (Sales Brain)
  ├─ /team                   (فريق العمل، المناطق، الأهداف)
  ├─ /agents                 (لوحة الوكلاء + الإعدادات)
  └─ /settings
       ├─ /settings/company
       ├─ /settings/pipelines, /fields, /tracks, /reasons, /scoring
       ├─ /settings/integrations
       ├─ /settings/billing  (الاشتراكات والاستهلاك)
       └─ /settings/audit

/(field)  ── شريط سفلي (PWA) — 4 تبويبات فقط
  ├─ /m/today                (زياراتي اليوم + المتابعات المستحقة)
  ├─ /m/visits/:id           (بطاقة الزيارة → Check-in → تسجيل النتيجة)
  ├─ /m/accounts             (عملائي — بحث)
  ├─ /m/tasks                (مهامي)
  └─ /m/me                   (الإعدادات، حالة المزامنة)

/platform  ── Super Admin فقط
  ├─ /platform/tenants, /platform/tenants/:id
  ├─ /platform/plans
  ├─ /platform/usage         (التكلفة الفعلية مقابل الإيراد)
  └─ /platform/health        (الطوابير، الأخطاء، مزودو AI)
```

## 3. تجربة المندوب — هدف: تسجيل الزيارة في ≤ 3 دقائق

```
[اليوم]  قائمة زيارات اليوم مرتبة بالوقت + زر "الاتجاهات"
   ↓ اضغط زيارة
[بطاقة الزيارة] (متاحة دون إنترنت)
   - لماذا هذا العميل (3 نقاط)
   - هدف الزيارة
   - 3–5 أسئلة مقترحة
   - أبرز الاعتراضات + الرد المعتمد (قابلة للطي)
   [ وصلت — بدء الزيارة ]
   ↓
[أثناء الزيارة]  [🎙 تسجيل (بعد الموافقة)]  [📝 ملاحظة]  [📷 صورة]
   [ إنهاء الزيارة ]
   ↓
[النتيجة — شاشة واحدة]
   النتيجة: ( مهتم | يحتاج متابعة | غير مهتم | لم يتم اللقاء )
   الاهتمام: ●●●○○
   الخطوة التالية: ( إرسال عرض | زيارة أخرى | اتصال | لا شيء )
   موعد المتابعة: [ اختيار سريع: غداً / 3 أيام / أسبوع / تاريخ ]
   ملاحظة صوتية أو نصية (اختياري)
   [ حفظ ]  → "تم الحفظ — سيتم التحليل عند الاتصال"
```

قواعد: أزرار كبيرة (≥ 48px)، إدخال صوتي في كل حقل نصي، لا أكثر من شاشة واحدة للنتيجة، حالة المزامنة مرئية دائماً.

## 4. نظام التصميم (ملخص)

- **الألوان**: محايدة (رمادي دافئ) + لون أساسي واحد (أخضر مزرق/Teal لهوية "راكان") + ألوان دلالية (نجاح/تحذير/خطر) + لون مميز خفيف لكل محتوى صادر عن AI مع أيقونة ✦ و "مصدر" قابل للنقر.
- **الخط**: IBM Plex Sans Arabic (عربي/لاتيني متناسق)، أرقام لاتينية افتراضياً مع خيار هندية.
- **المكونات الأساسية**: AppShell، DataTable، FilterBar، EntityHeader، Timeline، KanbanBoard، StatCard، AIInsightCard (مع المصدر والثقة)، ApprovalCard، SourceBadge، ConfidenceMeter، EmptyState، SyncIndicator، VoiceRecorder.
- **الحالات الإلزامية** لكل شاشة: Loading، Empty، Error، Offline (للمندوب)، No permission.
- **Dark mode**: P2.
