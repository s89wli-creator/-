# تقرير المرحلة الرابعة — الذكاء الاصطناعي (AI Intelligence)

> التاريخ: 2026-11-10 · الفرع: `claude/ecstatic-cray-v73b49`

## 1. ما تم بناؤه

### أ. أمان الحساب (مؤجل من المرحلة 3)
- **التحقق بخطوتين (TOTP)** متوافق مع Google/Microsoft Authenticator: رمز QR يُولَّد في الخادم، السر مشفّر، 8 رموز استرداد تُستخدم مرة واحدة، تحدي دخول صالح 5 دقائق بحد 5 محاولات (تُحفظ المحاولات الفاشلة حتى عند الخطأ).
- **تأكيد البريد الإلكتروني** عند التسجيل (رابط 48 ساعة، مرة واحدة) + تنبيه داخل التطبيق + إعادة إرسال.
- **الأجهزة النشطة**: قائمة الجلسات، وإنهاء أي جلسة (للمستخدم نفسه فقط).

### ب. طبقة الذكاء الاصطناعي
| المكوّن | التفاصيل |
|---|---|
| مزود مستقل | واجهة `LlmProvider`؛ التنفيذ الحالي Claude (`claude-opus-5-5`) بمخرجات منظمة يتحقق منها الخادم. **التحويل الاحتياطي من جهة الخادم مفعّل** (`fallbacks: "default"`): إذا تعذّر النموذج الأساسي يجيب نموذج احتياطي، ويُسجَّل اسم النموذج الذي أجاب فعلاً وتكلفته. |
| بدون مفتاح | تظهر رسالة صريحة "غير مفعّل" — **لا مخرجات وهمية أبداً**. |
| الميزانية | حد شهري لكل شركة (افتراضي 20$) يوقف الاستدعاءات عند بلوغه، تحذير عند 80%، مفتاح لكل مساعد. |
| السجل | كل عملية: من طلبها، النموذج، الرموز، التكلفة، وخطوات التحقق (`agent_runs` + `agent_steps`). |
| الحماية | حجب البيانات الشخصية (جوال/بريد/هوية/آيبان) قبل الإرسال للنموذج؛ تغليف النصوص الخارجية كبيانات غير موثوقة؛ فحص محاولات حقن الأوامر (عربي/إنجليزي) وعزل الوثائق المشبوهة؛ فحص العبارات الممنوعة. |
| Tool Gateway | كل إجراء بمستوى خطر. الإجراءات **الخارجية** (إرسال رسالة) تنتظر موافقة بشرية دائماً؛ يُنفَّذ المحتوى المعتمد حرفياً (يُتحقق من بصمته قبل التنفيذ)، ويُعاد فحص "عدم التواصل" لحظة الإرسال. |

### ج. عقل المبيعات (Sales Brain)
- 20 قسماً (نبذة، منتجات، أسعار، عميل مثالي، غير مناسبين، اعتراضات، خصومات، عبارات ممنوعة، آلية التسجيل والتعاقد…)، مع حقول منظمة للأسعار والاعتراضات والخصومات والمنافسين.
- إصدارات لكل تعديل؛ تعديل عنصر معتمد يعيده إلى "بانتظار التأكيد".
- كشف التعارضات (سعران لنفس المنتج، أكثر من قاعدة خصم، استخدام عبارة ممنوعة).
- وثائق نصية تُقسَّم وتُفهرس ببحث عربي (يتعامل مع "ال" والحروف المتشابهة)، ولا تُستخدم إلا بعد الاعتماد؛ الوثيقة المشبوهة لا يمكن اعتمادها.
- **لا يصل للنموذج إلا المعتمد.**

### د. المساعدون الأربعة
| المساعد | ما يضمنه الكود (لا النموذج) |
|---|---|
| تقييم العملاء | النموذج يقيّم المعايير مع مراجع؛ **الدرجة النهائية والفئة تُحسب في الكود** بأوزان الشركة. المعيار بلا مرجع صالح = صفر ويُسجَّل كبيانات ناقصة. جودة البيانات تُحسب بقاعدة. الاستبعاد يتطلب الاستشهاد ببند "غير مناسب" معتمد. مراجعة بشرية: اعتماد أو تعديل الفئة. |
| تجهيز الزيارة | نقاط القيمة والردود على الاعتراضات يجب أن تستشهد بعنصر معتمد، وإلا تُحذف وتُعرض في "ما تم حذفه" مع السبب. |
| تحليل الاجتماع | "ما قاله العميل" يُقبل فقط إذا كان الاقتباس موجوداً حرفياً في الملاحظات؛ الاستنتاجات منفصلة مع درجة ثقة. |
| رسائل المتابعة | لا مسودة لجهة "عدم تواصل" (قبل إنفاق أي تكلفة)؛ العبارات الممنوعة والادعاءات بلا مصدر تمنع الإرسال حتى التعديل؛ الإرسال عبر الموافقة فقط. البريد يُرسل بعد الموافقة؛ واتساب يعطي رابطاً يفتحه المندوب (لا تكامل إرسال واتساب في V1). |

### هـ. الواجهات
`/brain` · `/approvals` · `/settings/ai` · `/settings/security` · خطوة التحقق في الدخول · `/verify-email` · تبويب "راكان" في صفحة العميل · بطاقة الزيارة وتحليل الاجتماع في صفحة الزيارة. كلها عربية RTL + إنجليزية، وتعمل على الجوال 360px.

## 3. الاختبارات
- **API: 178 اختباراً** (منها 30 للذكاء الاصطناعي و6 للأمان) — جميعها ناجحة. مزود اختبار حتمي يمر بنفس التحقق من المخطط.
- **عزل الشركات: 92 فحصاً** (منها 29 لمسارات المرحلة 4) — ناجحة **حتى مع تعطيل RLS**، بما في ذلك التأكد أن عقل مبيعات شركة لا يظهر في مدخلات النموذج لشركة أخرى.
- **E2E جديد** (`pnpm e2e:ai`): تأكيد البريد، عقل المبيعات، العزل، الإعدادات، الموافقات، تفعيل التحقق بخطوتين ثم الدخول به، الجوال. أُضيف إلى CI مع الثلاثة السابقة.

## 4. التكلفة (تقديرية)
أسعار Claude المعلنة لكل مليون رمز: Opus 5.5 ‏4$ إدخال / 20$ إخراج. العملية الواحدة (تقييم أو بطاقة زيارة) تقارب 3–6 آلاف رمز إدخال و1–2 ألف إخراج ≈ **0.03–0.06$**. حد 20$ شهرياً يكفي تقريباً 350–600 عملية. يمكن للمالك تغيير الحد.

## 5. ما ينقص / القرارات المعلّقة
1. **مفتاح مزود الذكاء الاصطناعي**: الكود جاهز ومختبر بمزود الاختبار؛ التشغيل الفعلي يحتاج مفتاح Anthropic API وموافقتك على التكلفة.
2. **البحث الدلالي (pgvector)**: الاسترجاع الحالي بالبحث النصي العربي؛ التضمينات تحتاج مزوداً إضافياً (لاحقاً).
3. **مراجعة قانونية**: نقل البيانات (بعد الحجب) لمزود خارج المملكة — يلزم قرار قبل Pilot.
4. **مؤجل**: إرسال واتساب عبر API رسمي، العروض التجارية بالموافقات، تشغيل المساعدين بجدولة/أحداث (Worker)، التسجيل الصوتي.
5. منع إعادة استخدام رمز TOTP داخل نفس الـ30 ثانية (تحسين أمني صغير).
