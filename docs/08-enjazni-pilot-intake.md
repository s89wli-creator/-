# 08 — نموذج جمع معلومات Pilot انجزني

> الغرض: جمع معلومات Sales Brain الخاصة بانجزني **من الشركة مباشرة** قبل تفعيل الوكلاء.
> قاعدة: لا يُفترض وجود أي ميزة أو خدمة أو سعر غير مؤكد. كل حقل غير مؤكد يبقى بحالة **"بانتظار التأكيد"** ولا يستخدمه الوكيل.
> الموقع https://anjzni.com يُستخدم مرجعاً أولياً فقط.
