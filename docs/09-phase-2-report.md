### الشاشات

تسجيل الدخول، إنشاء حساب شركة، نسيت كلمة المرور، تعيين كلمة مرور جديدة، قبول الدعوة، الرئيسية، فريق العمل، المناطق، إعدادات الشركة، سجل التدقيق. كل شاشة فيها حالات: التحميل، الفراغ، الخطأ مع إعادة المحاولة، وعدم الصلاحية. لا توجد أزرار شكلية.

### اختبارات "الطفرة" (للتأكد أن الاختبارات تكشف الأخطاء فعلاً)

- تشغيل الـAPI بدور يتجاوز RLS (قبل إضافة فلاتر التطبيق): فشلت 5 اختبارات عزل ← **أضفتُ فلتر `tenant_id` صريحاً في كل الخدمات**، فأصبح العزل مضموناً من طبقتين مستقلتين، وكل طبقة تنجح وحدها.
- إضافة مسار API غير مصنف: فشل اختبار تغطية المسارات فوراً.
- إضافة `import { Pool } from 'pg'` داخل وحدة: رفضه ESLint (قاعدة معمارية).

## 3. الأمان — ما تم تطبيقه

| البند | التطبيق |
|---|---|
| كلمات المرور | Argon2id (m=19MiB, t=2) — توصية OWASP؛ حد أدنى 12 حرفاً |
| تعداد الحسابات | الدخول بحساب غير موجود يأخذ نفس الوقت ونفس رسالة الخطأ؛ "نسيت كلمة المرور" ترد بنفس الرد دائماً |
| القفل | 5 محاولات فاشلة → قفل 15 دقيقة + سجل تدقيق |
| الجلسات | رمز عشوائي 256-bit، يُخزن مجزأً (SHA-256) فقط؛ كوكي HttpOnly + SameSite=Lax + Secure في الإنتاج؛ انتهاء بعد خمول 12 ساعة وحد مطلق 30 يوماً؛ تدوير الرمز عند تبديل الشركة؛ إبطال كل الجلسات عند تغيير كلمة المرور |
| الصلاحيات | تُقرأ العضوية من قاعدة البيانات في **كل طلب** — التعطيل وتغيير الدور يسريان فوراً |
| CSRF | Double-submit token على كل طلب يغير البيانات |
| الرموز (الدعوة/الاستعادة) | 256-bit، تُخزن مجزأة، لمرة واحدة (Atomic)، بصلاحية محددة |
| السجلات | لا تحتوي كوكيز أو كلمات مرور (تم التحقق)؛ سجل التدقيق يحذف أي حقل يشبه سر |
| الإنتاج | يرفض التشغيل بكوكيز غير آمنة أو بدون SMTP حقيقي |
| الاعتماديات | إصدارات مثبتة؛ Next.js 15.5.28 المصحح من الثغرات الأمنية المعلنة في 15.x |

## 4. قرارات هندسية اتُخذت أثناء التنفيذ

| القرار | السبب |
|---|---|
| ملفات SQL هي مصدر الحقيقة للـMigrations (وDrizzle للاستعلامات فقط) | تحكم كامل في RLS والأدوار والصلاحيات؛ checksum يمنع تعديل Migration مطبقة |
| الأدوار الأربعة مخزنة كنص في العضوية، وصلاحياتها في الكود | تغيير صلاحيات دور يتطلب مراجعة كود؛ الأدوار المخصصة لكل شركة مؤجلة (P1) |
| تسجيل التدقيق صريح داخل نفس المعاملة (بدل Interceptor عام) | قيم قبل/بعد دقيقة، ولا يمكن أن ينجح التغيير ويفشل التدقيق أو العكس |
| الواجهة تتصل بالـAPI عبر نفس النطاق (Proxy) | لا CORS، كوكيز آمنة، لا مفاتيح في المتصفح |
| إصدارات راسخة (TypeScript 5.9، NestJS 11، Next 15.5) بدل أحدث الإصدارات الرئيسية | الاستقرار أهم في منتج تجاري؛ الترقية مخطط لها لاحقاً |
