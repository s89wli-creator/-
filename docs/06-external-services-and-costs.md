# 06 — الخدمات الخارجية والتكاليف

> ⚠️ **كل الأرقام تقديرية** بناءً على الأسعار العامة المعروفة وقت الكتابة (نوفمبر 2026)، وتتغير باستمرار.
> يجب التحقق من الأسعار الحالية وعقود المزودين قبل أي التزام. لن يُفعّل أي خدمة مدفوعة دون موافقة مسبقة.
> سعر الصرف المستخدم: 1 USD ≈ 3.75 SAR.

## 1. البنية التحتية (Hosting) — داخل المملكة

| الخيار | ملاحظات | التكلفة الشهرية التقديرية (Pilot) |
|---|---|---|
| **Google Cloud — منطقة الدمام** | Managed Postgres (Cloud SQL يدعم pgvector)، Memorystore Redis، Cloud Run، Cloud Storage | 250–600 USD |
| **Oracle Cloud — جدة/الرياض** | أسعار تنافسية، Postgres مُدار أقل نضجاً | 200–500 USD |
| **Microsoft Azure — منطقة السعودية** | التحقق من توفر الخدمات المطلوبة في المنطقة | 300–700 USD |
| **AWS — منطقة السعودية** | التحقق من الإطلاق والخدمات المتاحة | 300–700 USD |
| مزودون محليون (STC Cloud وغيرهم) | امتثال محلي قوي، قد تتطلب إدارة أكثر للخدمات | حسب العرض |

**التوصية المبدئية**: Google Cloud الدمام أو أي مزود يوفر Managed PostgreSQL مع pgvector داخل المملكة. القرار في نهاية Phase 3.

تفصيل Pilot (تقريبي): Postgres مُدار صغير مع نسخ احتياطي (100–200$)، Redis مُدار (40–80$)، حاويات API/Worker/Web (80–200$)، تخزين ونقل (10–40$)، مراقبة وسجلات (0–100$).

## 2. نماذج الذكاء الاصطناعي (LLM)

يتم الاختيار بعد **Evals عربية**؛ لا افتراض أن كل النماذج متساوية في العربية أو الأدوات.

| الاستخدام | الفئة | الأمثلة (للتقييم) |
|---|---|---|
| التحليل والتلخيص العربي المعقد (Meeting Intelligence، Brief، Coach) | نموذج قوي | Claude (Anthropic)، GPT (OpenAI)، Gemini (Google) |
| التصنيف والاستخراج البسيط (نوايا الردود، التطبيع، فحص الممنوعات) | نموذج صغير رخيص | فئات Haiku / mini / Flash |
| التضمين (Embeddings) | متعدد اللغات | نماذج تضمين متعددة اللغات من المزودين أو مفتوحة المصدر مستضافة ذاتياً |
| خيار سيادي/محلي | نماذج عربية أو مفتوحة المصدر مستضافة داخل المملكة | يُقيّم لعملاء Enterprise الحساسين |

### تقدير تكلفة AI لكل عملية (افتراضات)

| العملية | توكنات تقريبية (إدخال/إخراج) | النموذج | تكلفة تقديرية |
|---|---|---|---|
| تقييم عميل واحد | 4k / 0.8k | قوي | 0.01–0.03 USD |
| بطاقة زيارة | 8k / 1.5k | قوي | 0.03–0.06 USD |
| تحليل اجتماع (15 دقيقة نص) | 10k / 2k | قوي | 0.04–0.08 USD |
| مسودة متابعة | 3k / 0.5k | قوي/متوسط | 0.005–0.02 USD |
| تصنيف رسالة واردة | 1k / 0.1k | صغير | < 0.001 USD |

**مثال شهري لمندوب نشط** (80 عميل تقييم، 60 زيارة مع بطاقة وتحليل، 80 متابعة، محادثة): ≈ 8–15 USD (30–55 ر.س) لـLLM فقط.

## 3. تحويل الصوت إلى نص (STT) — عربي

| المزود (للتقييم) | ملاحظات | التكلفة التقديرية |
|---|---|---|
| OpenAI (Whisper / transcribe models) | جودة جيدة للعربية الفصحى، تحتاج اختبار اللهجة | ~0.006 USD/دقيقة أو أقل |
| Google Cloud Speech-to-Text (ar-SA) | خيار داخل نفس السحابة | ~0.016–0.024 USD/دقيقة |
| Azure Speech (ar-SA) | | ~0.017 USD/دقيقة (قائمة) |
| مزودون محليون متخصصون في اللهجات السعودية | قد يكون الأدق، يحتاج تفاوض | حسب العقد |
| Whisper مفتوح مستضاف ذاتياً | سيادة البيانات، يحتاج GPU | تكلفة خادم GPU |

مثال: مندوب بـ60 زيارة × 10 دقائق تسجيل = 600 دقيقة → 4–15 USD/شهر.

## 4. الخرائط

| المزود | الاستخدام | التكلفة |
|---|---|---|
| Google Maps Platform | Geocoding، Places (للـProspecting)، خرائط JS | رصيد/حصة مجانية شهرية ثم حسب الطلب؛ Places API من أعلى التكاليف — يجب وضع حدود صارمة |
| Mapbox / MapTiler + OpenStreetMap | عرض الخرائط | حصص مجانية سخية، أرخص للعرض |
| روابط الاتجاهات (Google/Apple Maps) | فتح التطبيق على الجوال | مجاني |

**التوصية**: خرائط العرض عبر MapLibre + مزود Tiles رخيص؛ Google Geocoding/Places فقط عند الحاجة ومع عداد استهلاك لكل مستأجر.

## 5. مصادر بيانات Prospecting

| المصدر | ملاحظات | التكلفة |
|---|---|---|
| Google Places API | بيانات عامة للأنشطة التجارية (الاسم، الموقع، الفئة، الهاتف العام، الموقع الإلكتروني) — الالتزام بشروط التخزين والعرض | حسب الطلب (~0.017–0.04 USD/طلب حسب الحقول) |
| مزودو البيانات التجارية المرخصون في السعودية | بيانات السجل التجاري وأنشطة الشركات | اشتراك سنوي، يُطلب عرض سعر |
| خدمات حكومية رسمية مفتوحة/مدفوعة للتحقق من السجلات التجارية | التحقق وليس الاكتشاف الجماعي | حسب الخدمة |
| مواقع الشركات نفسها | قراءة الصفحات العامة مع احترام robots.txt والشروط | تكلفة LLM فقط |
| إدخال المستخدم والملفات المستوردة | المصدر الأساسي في V1 | مجاني |

لا يُستخدم أي مصدر يمنع شروطه الجمع الآلي، ولا تُجمع بيانات شخصية للتسويق دون أساس نظامي.

### مقارنة مع الإيراد (افتراض 20 شركة على باقة Team 899 ر.س)

الإيراد ≈ 17,980 ر.س/شهر مقابل تكلفة تشغيل مباشرة 7,300–19,700 ر.س. **الاستنتاج**: هامش الربح يعتمد بشدة على ضبط استهلاك AI والـSTT والخرائط؛ لذلك:

1. أرصدة AI محددة لكل باقة (Hard limits) + باقات إضافية مدفوعة.
2. Model routing للنماذج الأرخص في المهام البسيطة + Prompt caching.
3. Prospecting و STT كاستهلاك محسوب منفصل.
4. مراجعة الأسعار بعد Pilot بناءً على التكلفة الفعلية لكل مستخدم (تُعرض في لوحة Super Admin).
